## 직원 상태 5종 (색상은 시각 자료 참고, 문서에서는 라벨로만 표기)

| 상태 | 뜻 |
|---|---|
| 완료 | 이번 단계 끝 |
| 진행 중 | 지금 작업 중 |
| 승인 대기 | 대표 결정 필요 |
| 연동 대기 | 외부 자료가 없어 멈춤 — 대표가 무엇을 줘야 풀리는지 반드시 한 줄로 명시 |
| 대기 | 앞 단계를 기다리는 정상 상태 |

## 대표 지시창 (질의 응답 규칙)

| 대표 입력 | 응답자 | 응답 내용 |
|---|---|---|
| "현황 보고" | 비서실장 | 현재 단계·진행 중 부서·다음 순서 |
| "왜 늦어져?" | 비서실장 | 진짜 병목 1개 + 원인만 (없으면 "지연 없습니다") |
| "[부서·이름] 뭐해?" | 해당 담당자 | 자기 팀 상황 |
| "회의 소집" | 팀장 전원 | 회의실 집결 후 한 줄씩 순서대로 보고 |
| "지금 브리핑" | 비서실장 | 대표에게 직접 보고 |
| "집중 모드" | 전원 | 자율 행동 중단 + 자리 복귀 |
| "승인할게" | — | 대기 중인 승인 건 처리 |

시각화된 상황판(부서 배치도 + 이동 애니메이션 + 지시창)은 별도 아티팩트로 제공하며, 이 문서는 그 데이터의 원본 기준이다.
